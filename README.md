# In The Digital World — Байтерек v1

Бесплатный браузерный FPS с ручной 3D-реконструкцией реального монумента **Астана-Байтерек**, исходные координаты **51.12829, 71.43046**.

> **Ключевая честность:** это **вновь созданная авторская модель Байтерека по известным пропорциям и визуальным референсам**, а не скачанная фотограмметрическая модель, не официальный BIM и не точная 3D-копия всего района. Здания из старого демо-квартала удалены. Озеленение, архитектура площади, дорожки, мебель и декоративные элементы пока приближённые. Пользователь может свободно ходить по сцене 1:1.

## Уже сделано

- Узнаваемый монумент: золотой шар диаметром **22 метра**, общая высота **105 метров**.
- Белые пространственные стойки, решётка, центральная шахта, основания и панелирование шара.
- Прогулочная зона ~370 × 370 метров с тротуарами, деревьями, лавочками и центральным кольцом.
- Вид от первого лица, WASD, мышь, Shift, Space, упрощённые коллизии, гравитация.
- Географические координаты игрока на основе реальной точки монумента (ориентация и расположение элементов площади — художественные приближения).
- Миникарта с отметкой монумента и игрока. **M**, кнопка «Карта» или клик по миникарте открывают увеличенную карту.
- 3 профиля качества, в том числе начальный **экономный** для встроенной Intel Arc.
- Не запрашиваются Google Maps/2GIS/Yandex API и не используются платные сервисы.
- Код запускается как статический сайт без сервера backend.

## Локальный запуск

```bash
git clone https://github.com/totKtoXam/inthedigw.git
cd inthedigw
python -m http.server 8000
```

Откройте `http://localhost:8000` в Chrome или Edge. Для библиотеки Three.js нужен интернет-доступ к CDN jsDelivr; самой 3D-сцене не нужны API или сетевые данные.

Управление: **WASD** — ходьба, **мышь** — взгляд, **Shift** — бег, **Space** — прыжок, **M** — развёрнутая карта, **Esc** — пауза, кнопка **↻ Начало** — возврат на точку старта.

## Тесты

```bash
npm run check
```

Используется только встроенный Node.js test runner, npm install не нужен. Автоматические тесты проверяют наличие архитектурных элементов, географические координаты, размеры, игровой контроллер, карту и отсутствие платных API. **Они не заменяют тестирование картинки, коллизий и FPS в настоящем браузере.**

## Что дальше, чтобы дойти до истинного цифрового двойника

1. Получить качественную лицензированную GLB-модель Байтерека **или** собственную 3D-фотограмметрию по фотосъёмке памятника. Кандидат для проверки лицензии — [Joker Boss, Sketchfab, CC BY](https://sketchfab.com/3d-models/1437567dff9d4d4dbf01ea78f03e3f00); модель **ещё не включена** в проект.
2. Заменить скульптурные элементы по точным чертежам, подтвердить ориентацию и размеры площадки.
3. Получить разрешённые реальные фотофасады и точные модели ближайших зданий; добавлять кварталы по частям.
4. Перейти на оптимизированные GLB/3D Tiles с LOD, текстурным атласом и офлайн-кешированием.
5. Отдельно проверить и оптимизировать FPS на ASUS Zenbook Duo / Intel Arc. Скриншот 60 FPS предыдущего **вымышленного** квартала не гарантирует такой же FPS на более сложной сцене.
