# In The Digital World — бесплатный браузерный FPS-прототип

**Статус:** `v0.1 / proof of concept`. Прототип исследовательской игры с **полностью свободным управлением от первого лица** в окружении, построенном по реальным контурам улиц и зданий. Оптимизирован под ноутбуки с интегрированной графикой, включая Intel Arc.

> **Про визуальную достоверность:** координаты дорог и контуры зданий в режиме OSM реальные, если присутствуют в OpenStreetMap. Фасады и текстуры **генерируются процедурно** и **не повторяют фотографии реальных объектов**. Это пока не графика уровня Google Street View. Достоверный фотоскан потребует отдельных лицензированных фотографий/съёмки и реконструкции сцены.

## Нулевой бюджет

| Ресурс | Использование | Оплата |
|---|---|---|
| Three.js | 3D/WebGL рендеринг | Нет; библиотека с открытым кодом |
| OpenStreetMap | Контуры зданий и дорожная сеть | Нет, ODbL, обязательна атрибуция |
| Overpass API | Точечный запрос данных вокруг стартовой точки | Нет для умеренного экспериментального использования, действуют общие ограничения |
| jsDelivr | Загрузка Three.js по CDN | Нет для прототипа |
| GitHub Pages | Публикация статического веб-сайта в публичном репозитории | Доступно на GitHub Free |

**Не нужны:** карты Google, API-ключи, Cesium ion, VPS, база данных или платные ассеты. Интернет нужен для первого получения данных OSM и для CDN Three.js.

## Запуск

1. Склонировать репозиторий.
2. В корневой директории запустить простой HTTP-сервер (вариант: `python -m http.server 8000`).
3. Открыть `http://localhost:8000` в Chrome/Edge и дождаться попытки загрузки OSM.
4. Нажать «ВОЙТИ В МИР»; браузер запросит захват мыши.

Открытие `index.html` напрямую через `file://` может не работать из-за ограничений ES-модулей и браузерной безопасности; запускайте через HTTP.

### Бесплатная публикация GitHub Pages

В настройках репозитория: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**. После публикации ожидаемый адрес: `https://totktoxam.github.io/inthedigw/`. Это **предполагаемый адрес**, а не подтверждение, что Pages уже активирован.

## Управление

- `W A S D` — ходьба;
- мышь — обзор 360°;
- `Shift` — бег;
- `Space` — прыжок;
- `Esc` — пауза/освободить мышь;
- `M` — скрыть или показать миникарту.

В меню есть переключатель Астана / Алматы / Париж и три уровня качества. При неуспешном запросе в OpenStreetMap запускается процедурный **демо-квартал**, явно обозначенный в HUD. Демо-квартал не является достоверной картой города.

## Архитектура

- `index.html` — интерфейс, карта управления, импорт Three.js;
- `style.css` — адаптивный HUD, меню, миникарта, стартовый экран;
- `game.js` — FPS-камера, геопривязка, загрузчик OSM, геометрия городов, коллизии, миникарта, LOD-подобные профили качества.

При запуске Overpass запрашивает только `way[building]` и `way[highway]` в квадрате порядка 540×540 метров вокруг выбранной точки. Данные преобразуются в локальные метрические координаты; фасады создаются через `THREE.ExtrudeGeometry`, дороги — полосами. Базовые столкновения рассчитаны от 2D-контуров зданий, персонаж имеет упрощённую физику прыжка и гравитации. Под землёй нет детализированного рельефа, все дороги приведены к плоскости.

## Ограниечения v0.1

- **Не фотореалистичные фасады.** OSM не предоставляет Street View изображения или текстуры.
- **Коллизии упрощены:** вертикальные стены от контуров, плоская земля, нет сложных лестниц и интерьеров.
- **Не полностью офлайн:** для загрузки Three.js нужен интернет; для OSM нужен доступ к Overpass. При сбое Overpass используется демо-квартал.
- **Ограниченный радиус мира:** реалистично обрабатываем один квартал, нет потоковой подгрузки новых районов.
- **Производительность не измерена на реальном Zenbook Duo.** Целевой ориентир — 30 FPS при экономном пресете, но это предстоит проверить.
- **Overpass — общий бесплатный сервер**, не рассчитанный на поток запросов от массовой игры. Не опрашивайте его непрерывно и не организуйте массовый production-трафик.

## Дальнейшие шаги к Street View-подобной графике без платных API

1. Получить собственные фотографии конкретного небольшого квартала с разрешением на переработку.
2. Построить фотограмметрическую 3D-модель / компактную 3D Gaussian Splatting сцену на бесплатной локальной или предоставленной среде (доступность вычислений проверять отдельно).
3. Экспортировать mesh / текстуры в glTF, оптимизировать LOD/размер и добавить физический collision mesh.
4. Подключить этот ресурс к текущему FPS-контроллеру, не меняя интерфейс управления.
5. Протестировать изображение, FPS и VRAM на Intel Arc, постепенно увеличивать доступную область.
